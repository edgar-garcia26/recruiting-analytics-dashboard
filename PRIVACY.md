# Privacy and data handling

This portfolio project is based on personal job-application history.

To protect private information, this public repository excludes:

- the original Excel tracker
- recruiter names and contact details
- private notes
- the unsanitized Application Details screenshot
- the original PBIX model containing record-level data
- local file paths and source references

The file `data/synthetic-sample.csv` contains fictional records created only to demonstrate the intended schema. It is not a sample of the user's real application history.
